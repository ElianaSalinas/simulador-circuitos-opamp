3. Oscilador Puente de Wien (03 - Oscilador Puente de Wien)
- Estado: Simulado y guardado exitosamente.
- Componentes y valores:
  * 1x Amplificador Operacional
  * Red RC simétrica: R = 10kΩ, C = 100nF (1e-7 F)
  * Resistencias de realimentación negativa: Rf = 21kΩ, Ri = 10kΩ (Ganancia de lazo = 1 + 21/10 = 3.1 para asegurar arranque y sostenimiento).
- Resultados (Teórico vs Simulado):
  * Frecuencia Teórica: f = 1 / (2 * π * R * C) = 1 / (2 * 3.1416 * 10k * 100nF) = 159.15 Hz.
  * Frecuencia Simulada: ~159 Hz (Medida visualmente en el panel del osciloscopio).
  * Forma de onda: Senoidal estable tras superar la etapa transitoria de arranque.

4. Multivibrador Astable con Op-Amp (04 - Multivibrador Astable con Op-Amp)
- Estado: Simulado y guardado exitosamente.
- Componentes y valores:
  * 1x Amplificador Operacional
  * Red RC para carga/descarga: R = 10kΩ, C = 1µF
  * Realimentación positiva (divisor de tensión): R1 = 10kΩ, R2 = 10kΩ.
- Resultados (Teórico vs Simulado):
  * Umbrales teóricos (Beta): 0.5 (mitad del voltaje de saturación).
  * Frecuencia Teórica: f ≈ 1 / (2 * R * C * ln(3)) ≈ 45.5 Hz.
  * Frecuencia Simulada: ~45 Hz.
  * Forma de onda: Cuadrada continua (alternando constantemente entre estados de saturación positivo y negativo).
